EDUCATIONAL: PASSWORD ENTROPY

THEORY

Password Entropy measures the unpredictability of a password, quantified in bits. It represents the logarithm (base 2) of the total possible password keyspace:

Entropy (H) = L × log2(R)
  • L = Password length (number of characters).
  • R = Size of the character pool (lowercase = 26, mixed alphanumeric = 62, full symbols = 95).
  • Keyspace = RL total combinations. Each additional character increases keyspace exponentially!
Entropy (Bits) Classification Crack Resistance
< 28 bits Very Weak Instant crack (seconds/minutes)
28 – 35 bits Weak Vulnerable to simple wordlists
36 – 59 bits Medium Moderate defense against casual probes
60 – 79 bits Strong Resilient against fast GPU rigs
≥ 80 bits Very Strong Cryptographically robust (> centuries)

PRACTICAL SECURITY RECOMMENDATIONS

BEST PRACTICES

Length Over Complexity

A 16-character passphrase composed of random words has vastly higher entropy than a complex 8-character string.

Never Reuse Passwords

Credential stuffing bots automatically test credentials leaked from one compromised service across thousands of others.

Use a Password Manager

Store cryptographically random, unique credentials in open-source or audited vaults (Bitwarden, 1Password, KeePass).

Enable 2FA / FIDO2 Passkeys

Hardware security keys (YubiKey) or TOTP authenticator apps prevent account takeover even if passwords are leaked.
